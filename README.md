# 🎨 FitHub — UI/UX Design (HCI Project)

A complete **UI/UX design** for a fitness application called **FitHub**, created in **Figma** as a 4th semester Human Computer Interaction (HCI) project at Air University.

The design focuses on creating an intuitive, user-friendly fitness experience by applying core HCI principles including usability, accessibility, and user-centered design.

## 📱 App Overview

**FitHub** is a fitness marketplace and tracking app designed to help users:
- Browse and purchase fitness products
- Track their workouts and progress
- Connect with fitness trainers and sellers
- Manage their fitness journey in one place

---

## 🎨 Design Features

- 🖼️ **Wireframes** — Low and high fidelity screen layouts
- 🎯 **User Flows** — Complete journey from onboarding to checkout
- 🎨 **Visual Design** — Consistent color scheme, typography, and components
- 📱 **Mobile-first** — Designed for mobile app experience
- ♿ **Accessibility** — Readable fonts, sufficient contrast, clear navigation
- 🔄 **Interactive Prototype** — Clickable flows between screens

---

## 🧠 HCI Concepts Applied

- **User-Centered Design** — Designed around real user needs and goals
- **Usability Heuristics** — Nielsen's 10 heuristics applied throughout
- **Information Architecture** — Logical content organization and navigation
- **Gestalt Principles** — Visual grouping and layout principles
- **Affordances** — Intuitive UI elements that guide user actions
- **Feedback & Response** — Clear visual feedback for user interactions
- **Prototyping** — Interactive prototype for user testing and validation
